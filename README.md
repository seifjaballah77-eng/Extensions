# Seif Extensions 💜

مجموعة إضافات متصفح من تطوير Seif، بهوية بنفسجية نيون ووضعين ليلي ونهاري.

## الإضافات
- **Seif AI** — أدوات مساعدة وتلخيص النص المحدد والصفحة الحالية.
- **Seif Privacy** — أدوات خصوصية وإدارة أذونات الموقع وفتح إعدادات الحماية.
- **Seif Download** — واجهة لإدارة التنزيلات وفتح صفحة التنزيلات.
- **Seif New Tab** — صفحة بداية بنفسجية قابلة للتخصيص.
- **Seif Translate** — ترجمة النصوص والصفحات عبر خدمة ترجمة خارجية.

## التثبيت
1. افتح مجلد الإضافة المطلوبة.
2. في Chrome افتح `chrome://extensions`.
3. فعّل **Developer mode** ثم اختر **Load unpacked** وحدد المجلد.
4. في Supermium استخدم صفحة الإضافات المقابلة إذا كانت واجهة Manifest V3 مدعومة في إصدارك.

> التوافق يعتمد على إصدار Chromium. بعض واجهات MV3 غير متاحة في إصدارات Supermium القديمة.

## الخصوصية
الإضافات لا ترسل محتوى التصفح إلى خادم Seif. خدمة الترجمة تفتح موقع ترجمة خارجي فقط عند طلب المستخدم. Seif AI في هذه النسخة يقدم أدوات محلية أساسية ولا يتطلب مفتاح API.

## المشاريع المستقلة
