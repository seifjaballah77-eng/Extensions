# Seif Extensions — NEON × GOLD

مجموعة إضافات متصفح بهوية ذهبية + بنفسجي نيون، مع وضع ليلي ونهاري.

## الإضافات
- **Seif AI:** استخراج النص المحدد وتلخيص أولي محلي للصفحة. ليست خدمة ذكاء اصطناعي سحابية.
- **Seif Privacy:** اختصارات إعدادات الخصوصية وأذونات المواقع. لا تدّعي حجب المتتبعات تلقائياً.
- **Seif Download:** عرض آخر التنزيلات وحالاتها وفتح مدير التنزيلات.
- **Seif New Tab:** صفحة بداية مع بحث واختصارات وتبديل المظهر.
- **Seif Translate:** فتح ترجمة النص أو الصفحة عبر Google Translate (يتطلب اتصالاً بالإنترنت).

## التنزيل والتثبيت اليدوي
1. اضغط **Code → Download ZIP** أو استخدم رابط تنزيل ZIP في الصفحة الرئيسية.
2. فك ضغط الملف إلى مجلد عادي.
3. افتح صفحة الإضافات في المتصفح: `chrome://extensions`.
4. فعّل **Developer mode**.
5. اضغط **Load unpacked** واختر مجلد الإضافة نفسها، مثل `seif-ai` أو `seif-privacy`، وليس المجلد الجامع.
6. كرر الخطوات لكل إضافة تريد تثبيتها.

## التوافق
الإضافات مبنية حالياً على Manifest V3. التوافق مع Supermium يعتمد على إصدار Chromium المضمن فيه؛ يجب اختباره على إصدارك قبل اعتماد التوافق. بعض صفحات `chrome://` قد تختلف حسب المتصفح.

## الخصوصية
لا توجد خدمة خلفية تابعة للمشروع تجمع بيانات التصفح. تُقرأ الصفحة الحالية فقط عند ضغط المستخدم على زر Seif AI. الترجمة تفتح خدمة خارجية عند طلب المستخدم، وبالتالي يُرسل النص أو رابط الصفحة إلى تلك الخدمة.

## ملاحظة
هذه نسخة تطوير أولية وليست مراجعة أمنية أو إصداراً منشوراً في متجر Chrome.
