# Seif Extensions — Gold × Neon Purple

موقع يجمع إضافات مستقلة للمتصفح. الهوية البصرية: ذهبي + نيون بنفسجي، مع خلفية سوداء أو بيضاء.

## الإضافات الموجودة
- Seif Capture: التقاط الجزء المرئي من علامة التبويب الحالية.
- Seif Image: اكتشاف صور الصفحة وتنزيل صورة أو رابط مباشر.
- Seif Translate: إرسال نص أو رابط صفحة إلى Google Translate عند الطلب.
- Seif Weather: الطقس الحالي، بيانات أرشيفية للأيام السبعة الماضية، وتوقعات الأيام السبعة القادمة. يعتمد على خدمات Open-Meteo والإنترنت.
- Seif Calculator: حسابات أساسية وخصومات وتقسيم الفاتورة.
- Seif Bookmarks: حفظ الروابط محلياً في المتصفح، والبحث والحذف والتصدير والاستيراد.
- Seif AI: استخراج النص المحدد أو إنشاء ملخص سريع من فقرات الصفحة؛ ليس نموذج ذكاء اصطناعي سحابياً.
- Seif Privacy: اختصارات إلى إعدادات الخصوصية وأذونات المواقع، وليس مانع تتبع تلقائياً.
- Seif Download: عرض التنزيلات الأخيرة وفتح مدير التنزيلات.
- Seif New Tab: صفحة بداية مع بحث واختصارات.

## تنزيل ملفات ZIP منفصلة
عند كل تحديث إلى فرع `main`، ينشئ GitHub Actions ملف ZIP مستقلاً لكل إضافة وينشرها في Release جديد:
[أحدث الإصدارات](https://github.com/seifjaballah77-eng/Extensions/releases/latest)

## التثبيت
1. نزّل ZIP الخاص بالإضافة المطلوبة وفك ضغطه.
2. افتح `chrome://extensions` في Chrome أو صفحة إدارة الإضافات المكافئة في متصفحك.
3. فعّل وضع المطوّر.
4. اختر **Load unpacked / تحميل إضافة غير مضغوطة**.
5. اختر مجلد الإضافة الذي يحتوي على `manifest.json`.

## حدود النسخة الحالية
هذه نسخ أولية تحتاج اختباراً عملياً على المتصفحات المستهدفة. Seif Capture يحفظ الجزء المرئي فقط حالياً، وليس صفحة طويلة كاملة ولا يتضمن OCR بعد. Seif Bookmarks يخزن البيانات محلياً ولا يزامن تلقائياً بين الأجهزة. دعم Supermium وWindows 7 غير مؤكد حتى اختباره على الإصدار الفعلي.

## الخصوصية
لا توجد خدمة خلفية خاصة بالمشروع تجمع بيانات التصفح. بعض الوظائف تتصل بخدمات خارجية عند استخدامها (مثل الترجمة والطقس). راجع أذونات كل إضافة قبل تثبيتها.
